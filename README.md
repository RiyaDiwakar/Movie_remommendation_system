# Movie_remommendation_system
# 🎬 Movie Recommendation System

A Streamlit-based movie recommendation system that suggests movies using
TF-IDF similarity and genre-based filtering, powered by TMDB data and a FastAPI backend.

---

## 🚀 Features
- 🔍 Search movies by title with autocomplete
- 🎯 Content-based recommendations using TF-IDF
- 🎭 Genre-based similar movie suggestions
- 📄 Detailed movie view (poster, overview, genres)
- 🌐 FastAPI backend + Streamlit frontend

---

## 🛠 Tech Stack
- Python
- Streamlit (Frontend)
- FastAPI (Backend)
- TMDB API
- Scikit-learn (TF-IDF)
- Pandas, NumPy
